# «Мой AI-редактор» — персональный новостной агент

Личный Telegram-агент Вадима Смирнова: проверяет подключённые источники об AI и технологиях, отбирает публикации и присылает короткие сообщения со ссылками.

**Статус:** личный серверный проект в использовании и доработке. Рабочий Telegram-бот принимает сообщения только от владельца. Для знакомства с проектом не требуется доступ к его личному чату.

## Посмотреть за две минуты

1. [Как устроен агент](docs/architecture.md) — источники, расписание, модель, отправка и ограничения.
2. [Запускаемый пример](demo/replay.mjs) — обработка учебной RSS-ленты без ключей и внешних запросов.

4. [Четыре проверки логики](tests/core.test.mjs) — ссылки источника, архивные новости, размер запроса и подтверждение ответа исходным текстом.

## Задача

Сократить ручной просмотр новостных лент. Получать объяснение «что произошло, почему полезно, что посмотреть дальше» и ссылку на публикацию. Задавать вопросы по уже сохранённой подборке.

## Реализация рабочего агента

- Проверка подключённых источников каждые 15 минут.
- RSS и адаптеры отдельных официальных страниц; фильтрация тематических лент.
- Сохранение публикаций и состояний обработки, отсечение повторов и старого архива.
- Обработка текста через Groq, проверка структуры ответа и фрагмента-подтверждения.
- Отправка в личный Telegram-чат и команды `/status`, `/pause`, `/resume`.
- Ответы по сохранённым материалам и ограниченная история диалога.
- Работа на сервере без включённого домашнего компьютера.

**Технологии:** JavaScript/TypeScript, Telegram Bot API, Supabase Edge Functions и база данных, RSS/Atom, Groq.

## Что опубликовано здесь

Это открытая витрина личного проекта и запускаемый фрагмент его логики. `src/core.mjs` скопирован из рабочего проекта без изменения; четыре проверки выбраны из его существующего набора тестов. `demo/replay.mjs` добавлен для демонстрации на вымышленных данных.

Серверный обработчик, база, расписание и привязка личного чата сюда не включены. Репозиторий не запускает Telegram-рассылку и не выдаётся за полный исходный код серверной системы.

## Проверить самостоятельно

Нужен Node.js 22+ и npm:

```bash
npm ci --ignore-scripts
npm test
npm run demo
```

Пример работает локально: читает вымышленную публикацию, подставляет заранее подготовленный учебный ответ модели и показывает итоговый текст. В демонстрации нет вызова нейросети и отправки в Telegram. Зависимости скачиваются только при установке.

## Мой вклад

Определил темы и требования, работал с AI-инструментами над кодом и настройкой источников, расписания и диалога. Проверял сообщения и исправлял поведение по результатам использования. Сам факт ответа модели не считаю подтверждением доставки сообщения.

## Ограничения

Агент читает выбранные источники, а не весь интернет. Не генерирует видео. Фильтрация, пересказ и автоматическая доставка требуют наблюдения и доработки. Проверка фрагмента исходного текста снижает часть ошибок, но не доказывает фактическую достоверность всех выводов модели. Важные утверждения проверяются по первоисточнику.
